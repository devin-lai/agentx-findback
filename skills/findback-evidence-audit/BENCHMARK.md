# Skill benchmark: FindBack evidence audit

The offline auditor accepted a real exported evidence report when its original source and trusted archive hash were supplied. It rejected altered member bytes and a wrong source. It also accepted eight older exports for internal consistency; several repeat the same generated scenario, so these are not independent accuracy cases.

In a small catalog routing check, an agent chose the intended first action on **8/8** prompts. In a separate single generated-fixture task, it ran the auditor and reported the verified result and limits. Neither check measures with and without Skill completion lift.

The auditor checks archive membership, hashes, citation timing and optional external hashes without executing code from the ZIP. A passing audit does not prove object identity or publisher identity when no independent checksum is available. The [competition results](../../docs/benchmarks/INDEX.md) state the wider product boundaries. Detailed receipts stay in private storage.
