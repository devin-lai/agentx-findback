# Code of conduct

AgentX FindBack welcomes contributors of every background and experience level. Treat people respectfully, give constructive feedback about the work, and make room for differing technical views.

Harassment, threats, discriminatory language, sexualized conduct, and publishing someone else's private information without permission are unacceptable. These expectations apply to project issues, pull requests, discussions and other project spaces.

The maintainers, [devin-lai](https://github.com/devin-lai) and [wingsuomo](https://github.com/wingsuomo), may edit or remove contributions and restrict participation when needed to protect the community. They will consider the circumstances and explain moderation decisions where doing so preserves the privacy of the people involved.

To report a concern, ask either maintainer for a private reporting channel without posting personal details in a public issue. Reports will be handled discreetly. For software vulnerabilities, follow [SECURITY.md](SECURITY.md).
